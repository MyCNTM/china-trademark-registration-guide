# Search goods and services

Find filing terms in English or Chinese across **{{catalogue_items}} items**. This searches the goods catalogue, **not registered trademarks or brand availability**.

<div id="tm-search" data-index="../data/search-index.json"></div>

## Build a working specification

Use **+** to add an item. Your list groups selections by class and estimates our standard package for one mark: USD 199 per class for up to ten items, plus USD 10 for each extra item. Copy the list or download CSV to discuss it with the service team. Additional proceedings are quoted separately.

## Read the result in context

| Field | Meaning |
|---|---|
| Class | One of the 45 Nice classes |
| Similar group | Chinese grouping used in similarity assessment; group notes and cross-references also matter |
| Chinese item | Wording to review for the Chinese application |
| English item | Translation to help you choose and review goods |
| Item code | Code retained from the source when supplied; some names have no code |

Selecting an item does not automatically protect all goods in its group. Choose genuine business needs and confirm the final specification before filing. [Read the classification guide](../guides/05-nice-classification-guide-china.md).
